# Resistor Toolkit (抵抗計算ツールキット)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

[English README](README_EN.md)

**Resistor Toolkit** は、電子工作愛好家、エンジニア、学生のための軽量でモダンなウェブベースの抵抗計算ツールキットです。
ビルドツールやNode.jsパッケージのインストールは不要で、ブラウザだけで快適動作します。

## 🔗公開ページ
[https://OtabiHirohito.github.io/ResistorToolkit/](https://OtabiHirohito.github.io/ResistorToolkit/)

## 🚀 主な機能

### 1. 抵抗カラーコード計算機 
- **4本帯・5本帯対応**: 標準的な4本帯カラーコードと高精度な5本帯カラーコードを瞬時に切り替え可能。
- **ビジュアル表示**: カラーバンドの選択に合わせて抵抗器のイラスト（SVG）がリアルタイムに更新されます。
- **許容範囲計算**: 公称抵抗値に加えて、許容差に基づく実際の抵抗値の最小・最大範囲を表示します。
- **カラー早見表**: 数字・倍率・許容差を一覧できるカラーリファレンステーブルを搭載。
![color-code](./color-code.png)

### 2. 表抵抗計算機 
- **10×10 グリッド入力**: マトリックス状の表に抵抗値を入力して合成抵抗を計算します。
  - **直列・並列接続**: 横方向（同一行内）の抵抗は直列接続、縦方向（各行同士）は並列接続として計算されます。
- **インタラクティブ回路図**: 計算結果の下部に、合成構造に対応するリアルタイムSVG回路図を表示します。
- **柔軟な数値入力**: 工学表記に対応（例: `100`, `1k`, `4.7k`, `1M`, `4R7`）。
- **キーボード操作**: 矢印キー（`↑` `↓` `←` `→`）でグリッド内をスムーズに移動可能。
![spreadsheet](./spreadsheet.png)

### 3. 数式抵抗計算機 
- **代数数式による合成計算**: 直列演算子（`+`）や並列演算子（`‖` または `||`）と括弧を組み合わせた数式を入力・計算（例: `1Ω + (2Ω ‖ 3Ω)`, `(100 + 220) || (330 + 470)`）。
- **等価抵抗 & 回路図自動生成**: 入力された数式の木構造から正確な等価抵抗を計算し、等価回路のSVG回路図を動的に作成します。
![formula-solver](./formula-solver.png)

### 4. 最適抵抗チェッカー 
- **目標抵抗値の最適探索**: 手持ちの抵抗値リストと目標抵抗値を入力すると、目標値に最も近くなる直列・並列の組み合わせ（回路トポロジー）を探索・ランク表示します。
- **パーセント誤差表示**: 目標値に対する誤差（Ωおよび%）を表示します。
- **回路図表示**: 提案された上位の回路構成ごとに回路図を描画します。
![network-solver](./network-solver.png)

## 🌐 多言語対応（日本語 / 英語）

初回訪問時はブラウザの言語設定を参照し、日本語環境では日本語、それ以外の言語環境では英語で自動表示されます。
画面右上の言語切替ボタン（`日本語` / `English`）により、いつでも手動で言語を切り替えることができ、選択した言語はブラウザに自動保存されます。

## 💻 ローカル実行方法

本プロジェクトは標準的なHTML5、CSS3、および JavaScript ES Modules で構築されているため、ビルド処理は一切不要です。

1. リポジトリをクローンまたはダウンロードします:
   ```bash
   git clone https://github.com/OtabiHirohito/ResistorToolkit.git
   cd ResistorToolkit
   ```
2. 静的Webサーバーでディレクトリを配信します:
   ```bash
   # Python 3 を使用する場合:
   python3 -m http.server 8000
   ```
3. ブラウザで下記を開きます。
   ```
   http://localhost:8000/
   ```
